FORM BEST PRACTICES07

Clear
Inputs

Text Field

Use for names, email, passwords, addresses. Always provide a clear label.

Dropdown

Use when there are many options and the user chooses one.

Checkbox

Use for multiple selections, settings, permissions, or agreement.

Validation

Give immediate feedback, explain the error, and show how to fix it.

Never rely only on placeholder text07 / 11
