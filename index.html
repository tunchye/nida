Overview

Interfaces are a conversation

UI components are the building blocks people use to interact with a product in a consistent, predictable way. Good components improve usability, accessibility, and satisfaction.

Interactivity is how those components respond to a click, a keystroke, a hover, a scroll — and effective feedback keeps the person oriented at every step.

Buttons

Three weights, one hierarchy

Buttons trigger actions — their visual weight should match how important that action is.

Primary Submit
  • High visual emphasis, filled background
  • Usually one per section
  • Save · Continue · Purchase
Secondary Cancel
  • Outlined, lower emphasis
  • Supports the primary action
  • Edit · Back · Learn more
Text link Forgot password?
  • Minimal visual weight
  • Best for navigation
  • View details · Read more

Cards & Containers

Group what belongs together

A card is a self-contained block — usually an image, title, description, and an action.

A container groups related components into one section, like a login form, dashboard panel, or product category.

Motion

Motion should explain, not decorate

  • Button ripple, menu slide, fade dialog, card expansion
  • Keep it fast — 150 to 300 milliseconds
  • Smooth and functional, never distracting

Key Takeaways

Four principles to build by

Hierarchy in buttons

Primary for the main action, secondary and text links for everything supporting it.

Clarity in forms

Clear labels, the right input control, and validation that explains itself.

Structure in layout

Cards and containers built on proximity, alignment, and generous whitespace.

Trust through feedback

Toasts, modals, loading states, and motion that keep people informed.
